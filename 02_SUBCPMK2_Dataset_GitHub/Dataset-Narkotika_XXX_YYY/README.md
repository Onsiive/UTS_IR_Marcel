# Dataset Narkotika — PN Tanjung Redeb (DRAFT; belum boleh diklaim terverifikasi)

Sumber yang digunakan sebagai input adalah 50 PDF ringkasan satu halaman yang diberikan pengguna, dan satu PDF tabel ringkasan 50 perkara. File ini **bukan berkas putusan lengkap yang telah divalidasi ke Direktori MA**. Tidak adanya tulisan "BHT" di PDF tidak membuktikan putusan tersebut belum berkekuatan hukum tetap.

Isi:
- `Dataset/Narkotika.zip`: 50 PDF ringkasan (kandidat, belum tervalidasi).
- `Overview/Overview.xlsx`: tabel ringkasan hasil ekstraksi dengan sheet audit; masih draft.
- `audit_50_pdf_DRAFT.csv`: temuan pemeriksaan.

**Sebelum pengumpulan:** cocokkan semua nomor dan substansi dengan putusan lengkap dari MA, verifikasi status BHT dari sumber otoritatif, ganti ringkasan 1-halaman dengan 50 PDF putusan lengkap non-BHT, lalu perbarui Overview sesuai dokumen resmi.
